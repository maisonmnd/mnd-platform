Déployer le code au serveur

Le code de l'offre voyage déjà du site jusqu'à la demande. Pour que le rendez-vous porte la remise, la fonction qui reçoit les réservations doit résoudre le code elle-même. Huit pas, dont quatre de vérification. Cochez au fur et à mesure : la page garde vos coches.

 
Phase I

Déployer la fonction

dix minutes · réversible

La fonction se livre entière, jamais en morceau. L'ancienne version reste dans l'historique du tableau de bord : un retour en arrière est un clic.

  1. Copier tout le fichier de la fonction

    Le fichier du dépôt est la seule version qui compte. Tout sélectionner, copier, sans rien retoucher.

    Où · dans le dépôt, supabase/functions/demande-submit/index.ts, depuis l'éditeur ou depuis GitHub (bouton « Raw », puis tout sélectionner).

  2. Ouvrir la fonction dans le tableau de bord Supabase

    Où · supabase.com/dashboard, projet de la Maison, rubrique Edge Functions, fonction demande-submit.

  3. Remplacer tout le contenu par le fichier copié, puis Deploy

    Effacer l'ancien contenu en entier avant de coller : un fichier collé à la suite d'un autre ne se déploie pas.

    Ne rien changer d'autre. Les secrets de la fonction (la clef de service, les clefs de notification, les clefs WhatsApp) restent en place : le nouveau fichier les lit exactement comme l'ancien.
Phase II

Vérifier sur une vraie réservation

cinq minutes · avec votre numéro

Une réservation d'essai, avec votre propre numéro, puis son annulation. C'est le seul moyen de voir ce que la cliente verra.

  1. Ouvrir la réservation du site avec le code dans l'adresse

    Cocher un lavage : le champ « Code de remise » est déjà rempli et la ligne dit son prix barré.

    Où · maisonmnd.com/revelateur/reserver/?code=RENTREE10

    Après le 30 septembre, « La rentrée des couronnes » ne court plus : utiliser le code de l'offre en cours, par exemple ROSE15 en octobre, sur un soin.
  2. Réserver avec votre propre numéro, un jour ouvert

    L'accusé WhatsApp arrive comme pour toute cliente. Rien d'autre ne change à cette étape.

  3. Ouvrir ce rendez-vous dans Le Trône et lire trois choses

    La note dit « Réservé depuis le site · code RENTREE10 ». La ligne du lavage porte −10 %, les autres lignes non. Le total est celui que le site a montré.

    Où · Le Trône, Calendrier, le rendez-vous du jour choisi.

    Au franc près : le site et Le Trône lisent la même règle.
    Si le total diffère, ne rien corriger à la main : dire l'écart, avec les deux montants. C'est la règle qui se corrige, pas le rendez-vous.
  4. Réserver une seconde fois, même numéro, même code

    Un autre jour, le même geste. Cette fois la remise ne doit pas s'appliquer, et la note doit dire « code RENTREE10 déjà utilisé par ce numéro ». La réservation, elle, passe normalement : on ne perd pas une venue pour une remise déjà prise.

    « Le code est utilisable une fois par personne. Non cumulable. » C'est le serveur qui le tient, parce qu'un navigateur ne sait rien des venues passées.
  5. Annuler ces rendez-vous d'essai dans Le Trône

    Ils ont servi ; ils ne doivent pas rester au carnet.

Ce que la fonction fait désormais

Elle fait

Elle résout le code contre les offres de la Maison : l'offre doit être active, dans sa saison, et couvrir la prestation.

Elle écrit la remise par ligne, sur les seules prestations couvertes au prix ferme. Un prix « au salon » n'est pas remisé.

Elle inscrit le code sur la demande et sur le rendez-vous, même quand il ne retire rien : un cadeau (NOEL) ou un code hors saison se comptent quand même.

Elle tient une fois par personne : un numéro qui a déjà reçu ce code ne le reçoit pas deux fois. Seul un rendez-vous ayant réellement porté la remise consomme la fois.

Elle ne fait pas

Elle n'écoute jamais un pourcentage venu du navigateur. Le navigateur n'envoie que le code.

Elle n'invente pas de remise pour un code inconnu ou périmé : le rendez-vous naît au prix de la carte, et la note dit « aucune offre en cours ».

Elle ne refuse jamais une réservation pour un code déjà utilisé, et ne l'écarte pas en silence : la note, le rendez-vous et la réponse portent la raison.

Elle ne touche pas à la remise de la cliente (la remise famille) : celle-ci porte sur tout le rendez-vous et vit ailleurs.
