Maquette à valider · 24 septembre 2026

Le code de l'offre

Une remise qui porte un nom : la Maison l'écrit une fois, la cliente le voit sur la carte, il se remplit tout seul quand elle réserve, et il reste sur la demande. On sait alors ce que chaque offre a réellement rapporté.

Le constat

Aujourd'hui, le « −10 % » est une phrase

Avant de construire, ce que j'ai lu dans vos offres, telles que le site les lit.

« La rentrée des couronnes » et « Octobre Rose » ne portent aucune remise chiffrée. Elles ont un titre, un texte, des dates. Le champ « Remise appliquée » du Trône est vide sur les deux, et la case « Prestation liée » aussi.

Le « −10 % » affiché est du texte, pas un nombre. Rien ne pouvait donc être déduit d'un prix : il n'y avait rien à déduire.

Et le Trône ne laisse attacher qu'UNE prestation à une offre, quand la vôtre en couvre deux familles. C'est ce que cette maquette répare.

Premier écran · au Trône

L'offre gagne un code et ses prestations

Deux champs de plus sur la fiche que vous connaissez, et une liste à cocher. Cochez, changez le code, le reste de la maquette suit.

Le code s'écrit une fois. Il ne distingue pas les majuscules et ignore les espaces : « rentree 10 » vaut « RENTREE10 ».

Ce que j'ai tranché, et que vous pouvez contester

Chaque ligne est une décision. Si l'une vous semble fausse, dites-le, elle se change avant que ce soit bâti.

Le casCe que fait la Maison
Une prestation dont le prix se dit au salon La remise ne s'y applique pas, et la ligne le dit. « GBÈJÍ™ Fidélité · Reprise & Shampoing Signature » est justement une reprise, mais son prix n'est pas ferme : rien ne peut en être déduit d'avance sans inventer un chiffre.
Une venue qui mêle couvert et non couvert La remise ne porte que sur les lignes couvertes. Le total montre chaque ligne, barrée ou non, pour qu'aucune surprise n'attende au comptoir.
Un prix qui se dit « à partir de » Le prix remisé se dit aussi « à partir de ». Le total reste un plancher, jamais une promesse.
Le code tapé hors de sa saison Il ne prend pas, et la page dit pourquoi : « Ce code a couru du 1er au 30 septembre. » Un refus muet ferait croire à une panne.
Un code inconnu La page le dit sans reproche et laisse réserver au prix plein. On ne bloque jamais une réservation sur une faute de frappe.
Deux offres qui couvrent la même prestation Un seul code à la fois, celui qui est écrit dans le champ. Aucun cumul : deux remises qui s'ajoutent sont la façon la plus simple de vendre à perte sans s'en apercevoir.
La Maison réserve depuis le Trône Rien ne change pour l'instant, à votre demande. La remise manuelle existe déjà à l'accueil. Le jour où vous voudrez que le code s'y propose tout seul, ce sera un ajout, pas une reprise.

Ce que je construirai si vous validez : le code et les prestations couvertes sur la fiche d'offre du Trône, le code écrit sur la carte du site, le lien qui l'emporte, le champ pré-rempli à la réservation, le prix barré ligne à ligne, et le code porté jusqu'à la demande. Le prix lui-même ne bouge pas d'un franc dans le catalogue : la remise se lit, elle ne réécrit rien.
