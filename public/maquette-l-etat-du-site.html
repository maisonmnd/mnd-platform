Ce qui tient, et c'est mesuré

Autant le dire d'abord : la fondation est saine. Ce qui suit est ce qu'un audit trouve rarement en ordre.

Chaque page a un titre unique, une description unique et bien calibrée, un seul H1, une canonical exacte, une image de partage, et un balisage structuré du bon type : HairSalon, Service, Article, FAQPage, Course, BreadcrumbList. Une seule entorse : le titre des CGU fait 62 signes, Google en coupe à 60.
Le texte est servi sans JavaScript : 544 mots sur l'accueil, 346 sur une page de service, 1061 sur un article. Google lit le site, pas un écran vide.
Toutes les redirections sont propres et en 301 : http vers https, www vers l'adresse nue, l'ancienne adresse GitHub vers le domaine. Une adresse inventée répond un vrai 404, pas un 200 déguisé.
Plus aucune trace de « L'atelier MND », aucun tiret cadratin visible, le fon avec ses signes dans une police auto-hébergée. La devise se lit comme elle s'écrit.
Le code de l'offre est en ligne de bout en bout : la carte servie dit « avec le code RENTREE10 », le bouton mène à l'entretien, la réservation le trouve rempli, et le serveur le résout.
